# Arunaashray

A static website project for the Aruna Ashray organization, built with HTML, CSS, and JavaScript.

## Project Overview

This repository contains the website for Aruna Ashray, including pages for services, contact information, donation details, mobile health camps, training programs, and more.

## Contents

- `index.html` - Home page
- `about.html` - About the organization
- `services.html` - Service offerings
- `contact.html` - Contact information
- `donate.html` - Donation page
- `mobile-health-camps.html` - Information on mobile health camps
- `mobile-payment.html` - Mobile payment details
- `virtual-training-programs.html` - Virtual training program details
- `bank-transfer.html` - Bank transfer information
- `holistic-care-center-advanced.html` - Holistic care center details
- `work.html` - Work and project listings
- `A-I-I-M-S.html` - Additional page content
- `CNAME` - Custom domain configuration
- `sitemap.xml` - Sitemap for search engines
- `style.css` - Main stylesheet
- `assets/` - Assets directory for CSS, images, and JavaScript

## Deployment

This is a static website and can be hosted on any static site hosting service such as GitHub Pages, Netlify, or Vercel.

The site is configured to use the custom domain: `www.ahcf.org.in` and is live at:

- https://www.ahcf.org.in

To deploy on GitHub Pages, push the repository to GitHub and enable Pages from the repository settings.

## Documentation

This README documents the repository structure and main site pages. Use the following guidance when updating the site:

- Edit page content directly in the HTML files for each page.
- Update the main stylesheet in `style.css` and `assets/css/style.css`.
- Place images in the appropriate `assets/images/` subfolder.
- Add or update JavaScript in `assets/js/script.js`.

## Notes

- The site uses standard HTML and CSS.
- Assets are organized under `assets/css/`, `assets/images/`, and `assets/js/`.
- Update any page content directly in the HTML files.
